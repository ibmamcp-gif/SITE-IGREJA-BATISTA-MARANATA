# Site Igreja Batista Maranata

Projeto estático premium montado a partir das telas exportadas pelo Stitch e ajustado com as imagens reais fornecidas.

## Executar localmente

Abra esta pasta no VS Code e use a extensão Live Server no arquivo `index.html`.

## Publicação

O projeto pode ser publicado diretamente no GitHub Pages, Vercel ou Netlify sem etapa de build.
